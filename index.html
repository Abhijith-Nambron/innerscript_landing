The Tragedy of the Silent Archive

You write for years. In paper notebooks, notes apps, private documents, random chats, and scratch drafts.

That writing contains your emotional curves, recurring fears, repeated habits, relationship histories, buried ambitions, contradictions, and solutions to problems you solved years ago but have now forgotten.

But because notes are stored in linear lists or disconnected piles, 99% of your journals become a silent cemetery. You almost never go back to read them. You repeat the same mistakes, ask the same unresolved questions, and suffer from the same alignment loops because you cannot converse with your own long-range memory.

System Specifications

Technical blueprint of the InnerScript local-first memory companion.

01 / ENCRYPTION LAYER

AES-GCM-256 Envelope Encryption

Database pages are cryptographically protected on disk. Decryption keys reside inside your operating system's native keychain (Keychain Access / Secret Service), never in memory or configuration files.

02 / LOCAL RETRIEVAL

On-Device Vector Search

Runs lightweight, localized Transformer model tokenizers via WASM. Vector computation is 100% offline, keeping sensitive memory files off corporate GPU clusters.

03 / ARCHIVE INGESTION

Multi-source Importer

Ingests DayOne JSON exports, Apple Notes database copies, and directories of markdown files. Automatically deduplicates entries and parses historical timestamps.

04 / ALIGNMENT EVALUATION

Grounding Verification Harness

InnerScript features a local verification framework that scans generated reflections. If a reflection makes an assertion about you that cannot be backed by a highlighted sentence citation in your database, it is automatically flagged and filtered.
